# Rol: desarrollador

Leer `docs/INDEX.md`, el plan y los documentos aplicables antes de abrir
código. Verificar luego en el archivo puntual que el plan sigue vigente,
reutilizar las capacidades existentes, implementar y ejecutar las pruebas o
validaciones proporcionales.

Antes de cerrar, actualizar la documentación si cambió un componente, hook,
cliente, contrato, flujo de sesión o regla no obvia reutilizable. Un ajuste
local y evidente no exige crear documentación nueva.

No dejar conocimiento requerido solo en memoria privada del agente: registrar
en `docs/` lo que otro agente deba reutilizar o continuar.
